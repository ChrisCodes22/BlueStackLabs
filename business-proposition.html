How these numbers are calculated

  1. Templates used is a direct count. The extension logs every insert to the admin portal in real time — no sampling, no estimates.
  2. Time saved values each insert at 2 minutes, the low end of the 2–3 minute range a production story actually takes to type by hand. The conservative figure was used deliberately.
  3. Labor value applies the $29.00/hr average technician rate to the recovered time.
  4. Cost is the actual invoice: 5 billed licenses at $10/month. Two licenses were issued at no charge; their usage is included in the savings but nothing is charged for them.

03 — Why the Savings Are Repeatable

The Same Repairs, Every Day

The 269 inserts were not a one-time push. They came from ordinary daily work, and the conditions that produced them are permanent features of a production floor — which is why the run rate holds.

Repetitive by Nature

Production sees the same repair types every single day. Technicians retype the same cause-and-correction format from memory each time — effort spent on work whose wording never changes.

It Compounds by Headcount

The measured rate is roughly 45 stories per active technician per month. That figure travels: every additional technician on the extension adds the same recovered time at the same $10 cost.

Documentation Quality

Hand-typed stories vary between technicians and carry spelling errors and missing steps. Every template insert is identical, complete, and correctly formatted — which matters downstream for warranty claims, audits, and repair history.

Onboarding

New production technicians do not need to learn the house documentation format before they can write an acceptable story. The template carries the standard for them from day one.

Primary Impact

Production Department

Production sees the highest volume of repeated work — the same vehicle, the same defects, the same stories written over and over. This is where the 269 inserts came from, and where each additional license returns the most. Every technician on the production floor is a candidate for the same measured gain.

The Admin Portal

The system now ships with a management portal built for the people overseeing the floor. Licenses, technician activity, and the value being returned are all visible in one place, updating live — which is exactly where the figures in Section 02 came from.

Live Usage Tracking

Template inserts register as they happen. A manager can see current activity rather than waiting for a month-end report.

Per-Technician Visibility

Usage is broken out by technician, so it is clear who is using the tool and who has not started — the difference between 6 and 7 active licenses is visible, not assumed.

License Management

Licenses are assigned, reassigned, and removed from the portal. Billing follows the licenses in use, so a seat that is not being used is not a seat you keep paying for.

Value Reporting

The portal computes recovered time and labor value against subscription cost on the same basis shown in this document, and exports it as a one-page summary for review.

Why this matters for approval

  1. The claim audits itself. This proposal does not ask anyone to take a savings figure on faith — the portal is the source, and it can be opened and checked at any time.

  3. Renewal is a data decision. At the end of any period, the return is a number on a screen, not an argument.
